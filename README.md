# Development Environment Docs

Operational documentation for the `/mnt/c/Development` environment.

## Scope

This repository versions the environment documentation that defines:

- environment structure
- truth-domain boundaries
- canonical versus imported asset policy
- knowledge graph workflow
- maintenance expectations
- environment design rationale

## Purpose

These docs are the operational truth for the shared development environment.

They describe how the environment works, how to maintain it, and how it should evolve without relying on chat history.

## Important Files

- `how-this-environment-works.md`
- `codex-environment-map.md`
- `canonical-promotion-policy.md`
- `knowledge-graph-operating-model.md`
- `hybrid-knowledge-workflow.md`
- `environment-design-rationale.md`

## Out Of Scope

This repository does not version:

- user runtime state in `~/.codex`
- canonical skills and imported AI assets under `system/ai`
- project repositories under `/mnt/c/Development/repos`
- the knowledge graph content itself
